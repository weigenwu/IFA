# 免疫荧光切片分区细胞计数

模块路径：`/if-count/`。在浏览器本地圈定区域，统计 DAPI 关联细胞、AF647 阳性细胞、GFP 阳性细胞及 AF647/GFP 双阳性细胞。输入图像不上传服务器；原始图像和原始通道不被改写。

## 通道和输入

本例已确认：DAPI 为蓝色，AF647 显示为紫色/洋红，GFP 为绿色。颜色是显示约定，通道选择仍须与文件的实际通道对应。优先使用保留独立通道的二维 OME-TIFF、受支持的 OIR 或同尺寸、已对齐的分通道文件。网页不执行通道配准；OIR 最大强度投影等读取处理沿用图像读取器的警告并写入导出。

VSI 与其配套 ETS 数据需在网页外转换为保留通道的二维 OME-TIFF 后再导入；当前网页不直接读取 `.vsi`，也不能只凭一个 VSI 描述文件恢复缺失的 ETS 像素。

RGB JPEG/PNG/合并 TIFF 的 R/G/B 是显示分量。洋红 AF647 会同时写入 R 和 B，蓝分量不再等于纯 DAPI；JPEG 压缩和显示范围还可能改变阳性判定。只有用户明确勾选探索性分析后才允许计算这类输入，并在结果中保留 `displayOnly`。不能由 RGB 合并图精确恢复独立 AF647 与 DAPI，不自动把 R 从 B 中相减。

## 显示与原始强度

独立原始通道默认开启“增强显示”：每通道等步长采样不超过 50,000 个像素，以采样强度的第 1 与第 99.8 百分位作为线性显示窗口；窗口无跨度时回退为 0 至通道最大值。RGB 展示图不应用该增强，保留原显示分量。增强显示仅影响预览与导出标记 PNG，二者使用同一渲染函数；不改变原始信号、计数阈值或结果，也不能据此比较不同图像的荧光强弱。

强度阈值按 0–255 输入，再分别映射到对应通道的原始强度范围；界面同时列出 DAPI / AF647 / GFP 的原始单位阈值。ZIP 的单图 JSON 将此次 PNG 渲染使用的原始单位显示窗口按上述通道顺序记录在 `display.rangesDapiAf647Gfp`，并记录是否启用增强。显示窗口与测量参数分别保存。

## 空间分区

用户逐图手绘组织外轮廓及若干命名内区域，可修改区域名称和边界。按细胞核质心位置分区，同一细胞只计入一个区域。命名内区域按列表顺序优先匹配，重叠部分归先匹配的区域；组织外轮廓内扣除各内区域后的剩余部分独立统计。组织外、未圈定和无效边界不被自动当作神经外膜。

神经束内为神经内膜所在区域，包绕神经束的边界为神经束膜，神经束之间及整个神经外围的结缔组织为神经外膜。整个圆形神经束不能等同于一层“内膜”；圈外的黑色背景也不是“外膜”。参见 [Duke University：Nerve](https://histology.oit.duke.edu/MBS/CellSci/CS-Nerve/CS-Nerve.html)。单凭当前荧光染色不会自动确定组织学边界；本工具将用户确认的 ROI 作为分区依据。

## 细胞与阳性判定

1. 用 DAPI 阈值和可选 3×3 中值处理建立核掩膜，按 8 连通域识别候选核，再按面积及触边规则筛选。核强度阈值使用原始通道单位；显示调色不参与计算。
2. 每个核建立“核本身 + 指定半径内邻域”的测量区域。邻域像素按最近核像素归属，互不重叠，避免同一个荧光像素被多个核重复使用。半径是像素距离，核关联邻域不等于真实细胞膜分割。
3. 在每个测量区域内，分别计算 AF647 和 GFP 高于各自阈值的像素占比，并与设定的最小阳性占比比较。超过强度阈值使用严格 `>`；阳性占比达到门限即为阳性。
4. 同一核关联对象同时达到两种标记的阳性条件，记为“双阳性细胞”。这不是严格像素共定位或分子相互作用的证据；两个标记可以分布在该对象的不同位置。不要用双阳性细胞数代替 Pearson/Manders 或亚细胞共定位分析。

阈值、核面积和核周半径需用代表图、阴性对照及人工检查确定。粘连核默认仍是一个连通域，碎片、核周信号串扰和密集组织需复核；本工具不自动推断细胞类型、神经束边界或实验组。核周区域跨解剖边界时，细胞仍按核质心归属，不能把邻域当作组织学轮廓。

## 批量、导出与复核

批量计算采用冻结参数，保留每张图自身的 ROI 和通道设置。已勾选复核，或已有任何细胞人工修正的图像，会跳过批量重算，避免覆盖人工工作；需要替换时可明确选择“计算此图”。修改区域或通道后，对应旧结果失效，需重新计算。

重新计算失败时保留该图上次成功的结果，并明确记录最近运行错误。汇总 CSV、逐细胞 CSV、单图 JSON 和 ZIP 的 manifest 均记录该错误；汇总 CSV、JSON 与 manifest 另外记录保留结果的计算时间，不能把旧结果视为本次统一参数计算成功。坏文件不阻止后续图像计算。

输出包括按图像/区域汇总、逐细胞记录及可追溯设置；记录原始文件名、SHA-256、通道映射、阈值和面积/半径参数、ROI 坐标、计算时间、展示图标记、警告与人工复核状态。读取器返回的来源格式及警告保存在快照中，来源警告也合并进结果检查提示，包含 OIR 投影或采集完整性等信息。原始来源、自动判断和人工修正应能够区分。

比例分母为相应区域内有效细胞数；无有效细胞时比例记为缺失，不能当作 0%。已计算结果不代表完成组织学复核；用于实验比较前需检查细胞标记及区域归属。该模块不计算 p 值，也不把单张切片内细胞当作独立生物学重复。
