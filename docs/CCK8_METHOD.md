# CCK-8 数据输入与计算说明

本工具在浏览器本地读取和计算数据，不上传实验表格。工作区保存在当前页面内存中；关闭或刷新页面前请导出。当前不直接解析 `.xlsx`：请从 Excel 复制单元格区域，或另存为 UTF-8 CSV/TSV 后导入。支持多文件；每个文件不超过 10 MB，工作区最多 10,000 孔。

**输入格式**

| 模式 | 必需结构 | 说明 |
| --- | --- | --- |
| 分组长表 | `组别/group` 和 `OD/OD450/吸光度` | 一行一孔。可附加 `批次/plate`、`时间/time`、`样本/sample`、`孔位/well`、`类型/role`、`参考OD/reference`、`排除/excluded`。 |
| 分组宽表 | `组别/group` 和 `重复1、重复2…` 或 `rep1、rep2…` | 每个复孔列展开成一孔，孔位记录为复孔列名；可附加批次、时间、样本、类型等字段。不能同时提供 OD 长表列或单独孔位列。 |
| 96 孔板 | 恰好 8 行 × 12 列读数 | 可附加按序排列的 1–12 列标题和 A–H 行标签，映射为 A1–H12；不自动识别组别、对照或空白。 |

CSV 支持引号内逗号、双引号转义和换行；支持 Excel 粘贴的制表符格式、UTF-8 BOM 和 CRLF。缺失值仍须保留相应分隔符。空白复孔保留为记录，只有完全空白的行被忽略。破损引号、重复标题、列数不一致和错误板形会报错；不支持的额外列会提示，原始输入文本仍保留在导出 JSON 中。

未填写批次时使用来源文件名（包含扩展名）；未填写时间和样本编号时留空。同名文件不能重复添加。不同文件只有在批次和时间被明确设置为相同值时才合并计算；时间为空的记录也属于同一个“空时间”范围。模板和示例数字仅供演示，需替换为实际实验值。

**映射与排除**

孔类型接受 `sample/样本/实验`、`control/对照`、`blank/空白`，缺省为实验孔。组名写成“对照”不会自动设置孔类型。96 孔板导入后须在“数据与分组”中明确填写组别、类型、批次和时间；缺少批次或实验/对照组别的孔不参与计算。

公共空白的类型设为空白、组别留空；某组专用空白的组别必须与该组一致。专用空白优先于公共空白；如果存在专用空白但全部无效，该组不会退回使用公共空白。空白应对应不含细胞且符合实验设计的背景条件。样本编号用于标识独立实验样本，同一样本的技术复孔使用相同编号；编号本身不能证明生物学独立性。

可逐孔或批量修改映射、排除及恢复记录。同一批次和时间内，未排除记录中重复的物理孔位 A1–H12 会触发 QC，所有冲突行暂停计算，直至人工排除重复记录；大小写及前导零写法（如 `a01` 与 `A1`）视为同一孔。宽表的 `rep1` 等标签不当作物理孔位。

**计算约定**

所有背景、对照和汇总均限定在同一批次、同一时间点内，组别和样本标识再用于组内汇总。

1. 孔信号 = OD450 − 参考 OD。未使用参考波长时参考值按 0 处理；同一计算范围中只要任一已映射且未排除孔填写参考值，其余参与孔也必须有有效参考值，否则相应孔暂停计算。
2. 校正 OD = 孔信号 − 匹配空白孔信号均值。空白均值仅使用有效孔，并提示无效空白。选择“输入值已扣空白”时不再次扣空白；参考 OD 仍按上述规则处理，已完成参考扣除的输入请勿重复填写参考值。
3. 相对活力（%）= 校正 OD ÷ 对照校正 OD 均值 × 100。同一批次和时间只接受一个对照组；出现多个对照组时，不推断配对关系。缺少有效对照、对照均值不大于 0 或对照分组不明确时，活力留空，已有校正 OD 及其组汇总仍保留。
4. 对照有效孔的样本编号全部填写时，先平均各样本技术复孔，再等权平均各样本作为归一化分母；否则采用有效技术孔均值，并提示部分样本编号缺失。
5. 组汇总对校正 OD 和活力分别选择有效孔。某指标的有效孔都有样本编号时，先求同一样本的技术复孔均值，再等权汇总样本均值；否则报告技术孔均值。`n` 对应实际汇总单位，技术孔数不能作为生物学重复数。SD 使用 `n−1` 分母，少于两个汇总单位时留空；图中误差线为 SD。

空白、`Undetermined`、无效或非有限数值不会变成 0。原始数值字符串保留；负校正 OD 和大于 100% 的活力保留并提示，不截断、不自动删除异常孔。工具不自动推断分组、独立性或显著性，不进行 p 值检验，也不将读数直接换算为细胞数。

Dojindo 的 [Cell Counting Kit-8 Technical Manual（2020-02-12 修订）](https://www.dojindo.co.jp/manual/CK04e.pdf)采用 450 nm 读数，并说明可通过扣除空白去除培养基背景；细胞悬液浑浊较高时，可测量并扣除 ≥600 nm 的参考吸光度。该方法依赖脱氢酶活性，影响代谢/脱氢酶活性的条件或化合物可能使 CCK-8 信号与实际活细胞数量不一致。上述分层、样本等权汇总、缺失值处理及 QC 是本工具的实现约定，不属于厂家规定的统计方案。

**导出与复核**

“导出 CSV”保存组汇总；“完整数据 ZIP”包含：

- `CCK8_汇总.csv`：两种指标的均值、SD、有效孔数、汇总单位、n 及 QC。
- `CCK8_逐孔明细.csv`：来源文件和行号、当前映射、排除状态、导入时原始 OD/参考 OD、当前 OD/参考 OD、逐步计算值及 QC。
- `CCK8_活力样本均值.csv`：有样本编号且可计算活力的孔形成的样本均值和技术孔 SD。此表不包含仅有校正 OD 的样本；相应结果查看组汇总和逐孔明细。
- `CCK8_原始输入与设置.json`：原始输入文本、导入解析记录、计算时映射及原始数值字符串、空白模式、计算时间和 QC。CSV 中可能触发 Excel 公式的文本会加保护前缀，需核对精确原文时使用此 JSON。
- `CCK8_当前图.svg`：存在有效图表时保存当前选择指标的图。

修改数据或设置后必须重新计算，旧结果导出按钮会暂停使用。此处“保存原始输入”指可追溯导出，当前没有 JSON 工作区重新导入功能。

截至 2026-10-27，已运行项目 `npm test`，116 项测试通过；覆盖 CCK-8 导入、计算边界及现有模块回归。另在本地浏览器验证了模拟示例、整板 96 孔批量分组、多 CSV 导入共 102 孔、分批次时间计算、修改后导出失效及重新计算。实际下载并核对 CSV / ZIP：10 孔示例保留原始输入、逐孔计算、2 组汇总及 SVG；处理组活力为 0.54 / 0.995 × 100；两个独立 CSV 的处理组分别为 50% 和 25%。这些是合成数据软件验证，不代表真实实验结果验证。
