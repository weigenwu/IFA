# EdU 分析与红色碎片清理

入口：https://weigenwu.github.io/IFA/edu/

## 先明确统计口径

本工具将蓝色核通道作为细胞核分割依据，红色作为 EdU 通道。用户应在每批实验中核对通道；`ch00/ch01` 是文件编号，不保证对应固定染料。本次需求统计全部细胞核，共培养中的 NK 也纳入分母。结果名称为“混合细胞群 EdU 阳性核比例”，不能解释为 JIMT 单独的增殖率。

EdU 阳性率（%）= 经复核的 EdU 阳性核数 / 经复核的有效细胞核总数 × 100。无有效核时返回空值，不当作 0%。EdU 反映标记时间窗内的 DNA 合成，单张终点图不直接给出细胞增长速度。

## 图片去杂色

红色残缺小块优先用强度下限与连通区域最小面积筛选。检查处理前后图，逐步调整到孤立碎片减少、完整核内红色保留的位置。弱小核内斑点可能是有效 EdU 信号，不能仅凭“不完整”就断定是噪声。面积阈值按原始像素计算，换物镜或图像分辨率需重设。

“保护核内红色”保留与合格蓝色核区域相交的小红色连通域；“仅保留核关联红色”额外排除完全不与核相交的红色连通域。被保留的连通域保持原形，不沿蓝色轮廓强行裁切。两项都是辅助显示规则，不能代替人工确认碎片来源；红蓝错位或分割遗漏时可能误删真实信号。

显示清理输出派生图，保留原图；它不进入 EdU 定量。展示相同实验的比较图应采用相同、预先固定的处理规则，并保存处理参数。不要为达到预期趋势逐图修改阈值。

整文件夹统一处理：导入文件夹并设置一次清理参数，点击“一键处理并导出”。所有视野使用启动时的红蓝背景下限、最小面积、核内保护、仅核关联和核支持参数，自动清理并导出 DAPI、RED、Merge 三张原尺寸 PNG。完成后自动下载本批次 ZIP，不混入此前其他文件夹或不同参数的保存结果；每个视野附参数 JSON，总清单记录成功、失败和停止情况。遇到坏文件继续处理其他视野；中途停止或部分失败的下载会明确标注“部分完成”。此功能不修改已计算的 EdU 统计。

也可逐张处理：处理好一个视野后使用“保存并下一张”，保存该视野的 DAPI、RED、Merge 三张原尺寸 PNG 和对应参数。最后“全部导出”一次下载 ZIP；当前已经预览但尚未保存的视野也会加入。不同视野各自保留保存时的清理效果，RED 与 Merge 使用同一份红色清理结果。切换文件夹可继续累积；这些保存结果只存在当前页面会话中，关闭或刷新前请下载 ZIP。

图片 ZIP 布局：所有 DAPI、RED、Merge PNG 直接放在同一层，文件名为 `序号_原视野名_DAPI.png`、`序号_原视野名_RED.png`、`序号_原视野名_Merge.png`，不再逐视野建文件夹。通道分文件输入使用去掉 `_ch数字` 后的共同视野名；唯一序号防止不同输入目录同名覆盖。参数集中于 `_metadata/*.settings.json`，总清单记录实际三通道文件路径、参数路径、完整来源和处理状态。该布局同时适用于“一键处理并导出”和逐张保存后的“全部导出”。

## 分析步骤

1. 导入文件夹或多张图。相同相对目录和视野编号的 merge/ch00/ch01 属于同一视野，不重复计数；保留子目录路径，避免自动推断生物学分组。
2. 核对蓝色核、红色 EdU。合并 RGB/单色伪彩图需明确确认探索性分析；优先使用保留原始强度的灰度 TIFF 或 OME-TIFF。LIF 请先在 Leica LAS X 或 Fiji/Bio-Formats 导出各原始通道，不叠加标尺、不调整 LUT 后再烧录为 RGB。
   预览区同时显示 DAPI、RED、Merge；原图/去碎片切换、缩放与滚动同步。计数标记和人工修订只出现在 Merge，两个单通道保留信号视图。
3. 对蓝色核设定分割阈值，可选择 3×3 中值滤波，仅用于分割。用 8 连通区域、最小/最大面积和边缘排除筛选核候选。未实现分水岭自动拆分；粘连核应回到原图复核，密集视野建议 Fiji 的分水岭配合人工核对。
4. 排除烧录标尺和文字的区域，并检查排除区是否同时遮挡细胞。不能将白标尺算作红蓝双阳性细胞。
5. 在每个核掩膜中读取未经显示清理的 EdU 像素。红色值严格大于 EdU 阈值的像素占比，达到设置的最小比例时，核被判为自动阳性。阈值按阴性/未加 EdU 对照确定；自动或默认值只用于初步预览。核内平均 EdU 强度另行记录。
6. 可逐张运行，或点击“计算全部视野”一键处理当前导入文件夹。批次统一使用启动时的阈值与排除区，显示进度，可停止并保留已完成结果；读图或通道识别失败的视野会列出原因，其余继续。自动结果均为未复核；已有同参数结果复用，已有人工确认或改判的不同参数结果保留并列为跳过。每次运行分析自动累计结果，人工改判也同步更新。检查分割覆盖、粘连、漏检、碎片与边缘对象，必要时改为阳性、阴性或排除；复核完成后点“确认当前视野”或“确认并下一个”。尚未确认的结果也可导出，但 reviewed 为 false。修改计数参数会清除当前视野的旧结果，需重新分析。
7. “导出统计 CSV”将所有已计算视野汇总为一份 CSV，包含总核数、EdU 阳性/阴性数、阳性率、分组、复核状态及参数来源。换文件夹继续累计，关闭或刷新页面前请下载。去碎片图片通过“全部导出”打包为 ZIP；逐核 CSV 和包含参数、来源哈希、人工改判的分析 JSON 也可单独导出。跨视野汇总先确认是否属于同一生物学重复；多个视野和大量细胞不能直接冒充独立生物学重复。

## 解释边界

RGB 导出图可能已执行黑位截断、色表映射或压缩；能拆出 R/B 不代表恢复了采集原始强度。不同显示黑位的文件不宜直接做原始荧光强度比较。用于正式论文的 EdU 阳性率应在统一原始导出、对照锁定阈值和代表性视野人工计数核验后报告。软件测试只验证实现，不证明生物学计数准确。

本网页实现为透明的阈值/连通区域方法，不等同于 ImageJ 的分水岭或经过训练的核分割模型。
