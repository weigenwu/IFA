## 独立通道显示与 VSI 转换

新增“增强显示”默认用于独立原始通道。代码复查确认：每通道采样至多 50,000 个强度值，以 1%–99.8% 分位线性缩放；RGB 展示分量不应用增强。预览与标记 PNG 共享渲染函数，计算仍使用原始像素和原始单位阈值。单图导出 JSON 记录 `display.rangesDapiAf647Gfp`，界面显示映射后的三个原始单位阈值。这里记录实现检查，不将视觉增强当作计数准确性验证。

本次 VSI/ETS 已在网页外转换，文件层面确认输出含 3 个独立 `uint16` 通道，宽高为 2304×2304，维度为 C=3、Z=1、T=1，像素尺寸为 0.325 µm。Bio-Formats 转换前后三个通道逐字节一致，排除了 512×512 RGB 缩略图，没有投影或归一化。

真实文件暴露了 TIFF ImageDescription 尾部 NUL 终止符导致浏览器 XML 解析失败的问题。读取器现仅移除尾部 NUL，保留内部无效字符供解析器拒绝，并新增回归测试。浏览器重新导入后自动映射 DAPI → DAPI、AF647 → CY5、GFP → FITC，已完成描边、计算和 ZIP 导出。

增强显示开启/关闭分别下载两份 ZIP 后独立比较：区域汇总和逐细胞 CSV 逐字节相同，JSON 的 result/snapshot/regions/mapping/sourceFiles/reviewed/error 相同；PNG 实际像素不同且均为 2304×2304。增强时原始单位显示范围依次为 [1514,46688]、[3872,22916]、[6818,23823]，关闭时均为 [0,65535]。原始 TIFF 校验值与输出快照一致。检查记录在 `_audit/if-count-native-export-qa.json`。该结果仍标记为未复核，仅验证软件一致性，不代表完成阳性阈值校准或生物学计数验证。
