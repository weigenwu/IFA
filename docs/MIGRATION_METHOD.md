# 细胞划痕与 Transwell

两个独立入口：`/scratch/`、`/transwell/`。适用于明场单页 TIFF、PNG、JPEG；图像在浏览器本地处理。原文件不改写，不根据数字目录猜测实验组或生物学重复。

## 使用

1. 选择文件夹，查看一张代表图并调整参数。
2. 点击“批量计算”，整个文件夹使用本次启动时的同一套参数。可停止；失败和未处理图片不会伪装为零值。
3. 逐图核对标记。划痕可编辑两侧边界，Transwell 可添加或删除候选计数点；复核状态单独保存。
4. 导出全部 CSV 或标记图 ZIP。CSV 保留完整相对路径、源文件 SHA256、尺寸、参数、自动/人工状态与提示。修改参数后旧结果标注为旧参数，重新计算才更新结果。

## 划痕

针对竖向划痕：由 RGB 灰度图的局部标准差区分有细胞纹理区域与低纹理间隙，在固定纵向 ROI 内寻找接近指定中心的间隙，再生成左右边界。短小纹理干扰可忽略，较多行无法找到双侧纹理支持时返回缺失值，并提示人工描边；不会把识别失败当作完全闭合。

面积为左右边界之间的梯形积分，平均宽度为面积除以 ROI 纵向长度。单位为 px² 和 px；倍率名称不作为物理标定。所有时间点应使用相同 ROI 和分析参数。倾斜严重、横向伤口、低对比或完全闭合的图像应人工核对，必要时手动描边。

文件名末尾的 `_0H`、`_24H`、`_48H` 等识别为时间。只在完整父目录与去时间后文件名都相同时建议配对；文件名相同不证明已配准。跨时间点需确认同一视野、取景和分析范围一致。

`闭合率 (%) = (A0 − At) / A0 × 100`

0H 缺失/不唯一、0H 面积非正数、识别无效、图像尺寸或分析参数不一致时，闭合率留空。面积增加时允许负闭合率，不按预期趋势截断。闭合率描述划痕间隙变化，不能单独区分细胞迁移与增殖。

## Transwell

先按蓝紫色差与亮度识别染色区域，颜色种子用于减少灰黑膜孔的干扰；面积过滤排除小碎片。小染色区域取一个距离峰中心，大簇按峰间距估计多个中心。灰黑未染色图、其他染色配色不在当前算法适用范围内。

输出自动估计数、人工修正后估计数、染色面积、覆盖率和大簇数。计数点可增删，但不会随之修改染色覆盖率；两个指标分别保存。大簇内的峰不等于经核染确认的单个细胞，密集区域可能低估或过分拆分，因此自动输出是候选估计，需检查标记图。

该页面仅称“穿膜细胞计数”，不根据图片推断有无 Matrigel，也不自动解释为迁移或侵袭实验。不把多个视野自动当作独立生物学重复。

## 实现与参考

此实现使用本项目的 TypeScript 算法，不声称与 ImageJ/Fiji 输出一致，也未复制参考宏代码。参考工具的基本工作流：

- [MRI Wound Healing Tool](https://github.com/MontpellierRessourcesImagerie/imagej_macros_and_scripts/wiki/Wound-Healing-Tool)：划痕面积、局部方差/边缘方法、时间序列与文件夹处理。
- [ImageJ Particle Analysis](https://imagej.net/imaging/particle-analysis)：阈值区域、面积过滤和粒子检查的通用思路。

自动化测试检查几何面积、参数/输入校验、无信号行为、孔环抑制、聚簇估计、来源配对与 CSV 缺失值。真实图片叠图检查属于软件适用性检查，不是人工标注金标准验证；用于正式结果前，应以代表视野人工复核并固定参数。
